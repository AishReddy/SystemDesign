Capacity Estimation — Purpose

Why do we need capacity estimation?

01
🖥️
Determine servers & databases
Estimating DAU, MAU, and throughput tells us exactly how many servers and databases we need to handle the load.
Example
Server handles 1M req/hr but system needs 10M req/hr → provision 10 servers
02
💰
Cost management
Servers and databases cost money. Capacity estimation prevents overprovisioning (wasted spend) and underprovisioning (outages).
Goal
Provision exactly what is needed — no wasted resources, no surprise failures under load.
03
⚙️
Choose hardware type & specs
Query volume helps decide which type of database or hardware fits best for the workload.
DB comparison — 10M queries/hr

04
⚖️
Read heavy vs write heavy
Throughput estimation reveals the read/write ratio, which directly influences database and architecture choices.
